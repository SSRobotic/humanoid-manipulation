## 🚀 Start here

1. Check the planning group, end-effector definition and controller interface.
2. Use a documented planning or grasp example with the appropriate robot model.
3. Inspect collision geometry and coordinate frames; supporting arm examples are platform-specific.

Read the [engineering guide](GUIDE.md) for a practical selection checklist. [resources.json](resources.json) contains the structured entries.
